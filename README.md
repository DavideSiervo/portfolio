# Portfolio — Davide Siervo

Portfolio per la candidatura al Biennio di Musica Elettronica del Conservatorio di Torino.

## Pubblicazione con GitHub Pages

1. Creare su GitHub un repository pubblico chiamato `portfolio`.
2. Caricare nella radice del repository tutto il contenuto di questa cartella.
3. Aprire **Settings → Pages**.
4. In **Build and deployment**, scegliere **Deploy from a branch**.
5. Selezionare il branch `main`, cartella `/ (root)`, quindi **Save**.

Il sito sarà disponibile all'indirizzo:

`https://davidesiervo.github.io/portfolio/`

La pubblicazione può richiedere alcuni minuti.
