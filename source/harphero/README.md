# HarpHero

Videogioco musicale realizzato da Davide Siervo con Python e Pygame.

- `main.py`: versione adattata per l'esecuzione nel browser tramite Pygbag.
- `original/`: codice del prototipo originale.

Nel gioco, i nemici avanzano verso il centro mostrando una nota. Il giocatore usa i tasti C, D, E, F, G, A e B per suonare la nota del nemico più vicino.
